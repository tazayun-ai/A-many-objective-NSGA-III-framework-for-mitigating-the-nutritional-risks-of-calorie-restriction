# A-many-objective-NSGA-III-framework-for-mitigating-the-nutritional-risks-of-calorie-restriction
A many-objective optimization framework addresses diet side effects (mood, hair, muscle, hunger) via NSGA-III across six objectives. Tested on 2,307 USDA foods, it achieved 95.4% nutrient adequacy, outperforming standard reference diets.
